### データを取得する

```plantuml
@startuml
actor User
participant Web as "Web/Mobile"
participant API as "API(FastAPI)"
database DB as "RDB"
collections KV as "Redis/KV"

User -> Web: 画面表示要求
Web -> API: GET /items (Bearer Token)
API -> KV: キャッシュ参照
alt キャッシュヒット
  KV --> API: items
else キャッシュミス
  API -> DB: SELECT items
  DB --> API: items
  API -> KV: SET items(期限付き)
end
API --> Web: 200 OK (items)
Web --> User: 一覧表示
@enduml
```
